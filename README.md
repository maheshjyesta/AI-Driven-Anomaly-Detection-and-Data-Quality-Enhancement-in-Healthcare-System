# AI-Driven-Anomaly-Detection-and-Data-Quality-Enhancement-in-Healthcare-System
# 🏥 Healthcare Anomaly Detection — Generalised Edition

An AI-powered healthcare anomaly detection system that uses deep learning and machine learning techniques to identify abnormal patterns in medical datasets. This project focuses on detecting anomalies from real-world healthcare datasets such as ECG signals and breast cancer diagnostic data.

---

## 📌 Project Overview

Healthcare systems generate massive amounts of patient data every day. Detecting abnormal patterns manually is difficult, time-consuming, and error-prone. This project aims to automate anomaly detection using advanced AI models such as:

* LSTM Autoencoders
* Isolation Forest
* One-Class SVM

The system learns normal patient patterns and identifies unusual behavior or anomalies that may indicate health risks.

## 🧠 Models Implemented

### 🔹 LSTM Autoencoder

A deep learning model designed for sequential healthcare data analysis. It learns normal patterns and reconstructs them. High reconstruction error indicates anomalies.

### 🔹 Isolation Forest

An unsupervised machine learning algorithm that isolates anomalies based on random decision trees.

### 🔹 One-Class SVM

A machine learning approach used to separate normal and abnormal data patterns.
